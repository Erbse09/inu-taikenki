# 口コミ出典の確認台帳（2026-10-17）

PR #118 の追加調査。**本番D1は一切変更していません。** 台帳は静的ファイル（`src/review-source-ledger.ts`）で、サイトの表示だけに使います。

## 何をしたか
- 他サイトの要約として登録されている **1495件すべて**について、確認先（楽天・Yahoo!ショッピング等のレビュー一覧）の取得済みページ本文と突き合わせ、状況を記録しました。
- 突き合わせは自動の文字一致では精度が足りない（言い換えが多い）ため、生成AI（Claude）が候補となる投稿を**1件ずつ読んで**判定しました。読む対象は、自動の類似度が一定以上の行、猫の投稿が多い確認先の行、前回のサンプル行の計1,082行と、類似度が低かった行のうち先頭候補だけを見た217行。
- 読み比べていない行：キーワードがまったく重ならなかった64行（「見つからず」としました）と、本文を取得できなかった132行（「確認不能」としました）。
- サイト内記事を再整理した100件は、他サイトの体験ではないため台帳の対象外です（従来どおり別枠表示）。

## 状況の定義
| 記号 | サイト上の表示 | 意味 |
|---|---|---|
| V | 出典確認済み | 確認先の一覧で、内容が対応する投稿を見つけた。**その投稿が載っているページ**へのリンクを付ける |
| P | 出典 部分一致 | 近い内容の投稿はあるが、同じ投稿とは言い切れない。リンクなし |
| N | 出典 見つからず | 取得できた範囲では対応する投稿が見つからない。**作り話と判明したという意味ではない** |
| U | 出典 確認不能 | 確認先ページの本文を取得できなかった（商品ページ削除、JavaScript描画など）。リンクなし |
| C | 出典 猫の投稿の可能性 | 対応すると思われる投稿が猫の飼い主によるもの。犬の体験とは言えない。リンクなし |
| （表示なし） | 確認を実施していません | 台帳にない行（今後追加された体験など） |

- 「見つからず」429件のうち 365件は目視、64件は自動のみ（上記）。

## 行ID 550（Moizze PET001）
