- 猫の飼い主の投稿を犬の体験として登録している例は0件。一致した677件の投稿本文を「猫・ネコ・にゃん・ニャ・キャット」で検索し、出現した4件（127・256・407・635）はいずれも「犬が猫を見て反応した」という内容で、飼い主は犬の飼い主。

- 要約の元の数値に推測が混じっていないか：V の571件では、要約の犬種・体重・年齢・サイズ・月齢が投稿本文にあることを確認した（全角/半角・「才/歳」・「キロ/kg」の表記ゆれのみ差異）。

A の106件から30件（28%、乱数の種 106）を無作為に抽出し、**投稿の全文**と要約を1件ずつ読み直した。30/30件で、犬種・体重・年齢・サイズ・使用状況・不具合の記述が投稿と一致した（食い違い0件）。

## 確認の方法と限界
1. 各口コミの `source_url`（レビュー一覧ページ）を取得し、そのページの投稿一覧を解析した。口コミごとに、要約と投稿の文字列・数値の類似度が高い候補を選び、要約と照らし合わせた。
2. 一覧は更新で順番が変わる。最初に記録したページに無かった投稿は、同じ商品の近隣ページで探し直した（5件は元の `source_url` と別ページで見つかった。`review_sources.source_url` には**実際に見つかったページ**を登録する）。
3. 楽天の投稿には公開された固有IDが無い。識別子は `商品コード:投稿日:投稿者表示名のハッシュ8桁:本文の指紋10桁`。Yahoo!ショッピングは投稿ID（UUID）を使う。**原文は保存していない**（指紋＝正規化した本文のSHA-256先頭12桁のみ）。
4. リンク先は個別投稿の固定リンクではなく、その投稿が載っているレビュー一覧のページ。
5. 取得できたのは各確認先の先頭数ページ。商品の古い投稿は取得範囲外にある可能性があり、「見つからなかった」は「実在しない」ではない。
6. 判定はAIによる。誤りが残る可能性がある。
7. ページ本文に含まれる静的な体験カード11件のうち、動画由来の1件（黒柴）を、確認済みの別の体験（元野犬の保護犬）に差し替えた。柴犬12kg・イージーウォークのカード1件は、確認先に実在する投稿（Yahoo!）に基づくが、D1の口コミには含まれていない。
