# 次回公開のデータ差分

商品・口コミの追加は、出典を検証した追加差分SQLとしてここに保存する。
Previewでは既存本番データを読むだけ。ここに保存したSQLをPreviewで適用するコマンドはない。
新D1作成・本番D1複製・DB昇格方式は採用しない。データは別途公開承認後に既存本番D1へ適用する。
mainのコード公開とD1更新は同時トランザクションではなく、D1適用時にデータが公開される。
履歴の migrations/ や seed.sql を再実行しない。全DBコピーで本番を上書きしない。
SQLごとに変更理由・出典・想定追加件数・重複回避方法・検証結果を記録する。
試験専用データは本番用SQLに含めない。既存IDと source_type/source_url を保つ。
適用前後に件数だけでなく既存行の内容・関連整合性を比較する。
本番適用は公開承認後のみ。詳細は ../DEVELOPMENT.md。
