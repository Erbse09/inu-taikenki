## 3. 改稿時に追加できる「このサイトならでは」の比較軸（原稿案）

1. **製品仕様表**：製品名／刃の方式／適応対象（公式の記載そのまま）／本体重量（メーカー確認済みだけ）／調整機構（確認済みだけ）／出典URL・確認日。
2. **選び方の判断フロー**：まずメーカーの適応対象を確認 → ギロチンの穴へ爪を通す操作が必要か → 横から刃を当てる操作が必要か → 飼い主自身が安全に扱えるか。飼い主の好みと犬の反応を区別する。
3. **不明点の明記**：サイズ・重量・機能を確認できない製品は「公式情報で確認できず」とする。違いが確認できない項目では優劣をつけない。
4. **掲載根拠の整理**：公式仕様／獣医・専門機関の一般的な爪切りガイド／口コミ由来の個人的感想／運営者の実体験（ある場合のみ）を明確に区別する。

## 4. 本番のmeta descriptionに修正候補がある

2026-11-19の公開ページ `https://inu-taikenki.com/dog-nail-clipper` では、descriptionが「**Amazon・楽天など複数サイトの犬用爪切りの公開口コミ**...」となっていた。一方、リポジトリの`public/dog-nail-clipper.html`内の静的descriptionには「Amazon」と書かれていない。

これはWorker側の動的SEO上書きによる可能性があるため、**実際に出力されるdescriptionの生成箇所**を修正対象として調査すること。単に静的HTMLを修正しても本番の文言が変わらない可能性がある。

既存の編集方針はAmazonカスタマーレビュー本文を主な根拠にしていないため、**実態と異なる出典表現は避ける**。ただし当文書では記事・metaの実変更は行わない。
