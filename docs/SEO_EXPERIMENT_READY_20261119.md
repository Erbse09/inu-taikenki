## 4. 公開順序の選択（提案。未承認）

**推奨A：PR #115由来のSEO施策を現行main用に別途安全に再構成して審査 → 運営者承認後に公開 → 2〜4週間の観測 → 改稿実験を別日に公開。**

- 長所：PR #115によるtitle・FAQなどの影響を、改稿実験と時期で分けられる。短所：公開・観測が2段階で時間がかかる。

**代替B：現行mainでの対照群を固定し、3記事の改稿差分だけを個別に本番へ届ける。**

- developで記事を作る場合も、公開直前は現行mainから**改稿箇所だけ**を取り出し、PR #115の変更を混ぜない。ファイル丸ごとのコピーは避ける。
- 長所：実験開始を早めやすい。短所：差分の分離・レビューの難度が高い。
