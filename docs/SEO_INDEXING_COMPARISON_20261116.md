## 3. `/about.html` と `/about` の分析

### 3-1. 事実

| 内部リンク | 本番の全ページは `/about`（拡張子なし）にリンク | 実証済み |

### 3-2. 解釈

1. **Googleが旧URLを登録済みとして保持している可能性：高い（有力な仮説）。** Googleは「リダイレクトは、転送先を正規URLにする強いシグナル」と説明しているが、決めるのはGoogleで、URL変更の処理には数週間以上かかることがあるとも説明している。9/21に301を取得した後も、`/about.html` を「`/about` と同じ内容のまとまり（クラスタ）の代表」として残しているか、一覧の情報が古いままである可能性がある。
2. **正規URL変更後の再評価：** `/about` 自体が登録されていないので、Googleがまとまりの代表を `/about.html` のまま扱っている可能性がある。旧GitHub Pagesの複製が `about.html` をcanonicalとして指していたことは、その判断を後押ししうる要因だった（未確認）。この複製は11/16に404になった。
3. **レポートの更新の遅れ：** あり得る。`/about.html` の前回のクロールは8週間前で、それ以降の状態が反映されていない可能性もある（未確認）。
4. **他の記事への同様の影響：** 登録済み一覧に `.html` のURLは `about.html` しかない。ほかの記事の旧 `.html` URLは「ページにリダイレクトがあります（34件）」に移っていると考えられる（URL単位は未確認）。登録済みの4記事は拡張子なしURLで登録されているので、少なくともこの4本は移行が終わっている（実証済み）。
5. **技術的な修正は不要で、経過観察が適切。** 301・自己参照canonical・サイトマップ・内部リンクはすでに `/about` で揃っている。これ以上の技術的手段（canonicalの追加変更、URLの再変更など）は逆効果になりうる。Googleは転送を少なくとも1年維持することを勧めている。
6. **登録数の減少との関係：** 「登録済み6件」のうち1件は旧URLなので、**正しいURLで登録されているのは実質5件**。`about.html` の件だけで「約30→6」を説明することはできない。ただし、初期の .html URLが登録されていて、移行後に新URLの多くが未登録のまま、という説明（B3）の具体例にはなる。

### 3-3. 確認方法（運営者が実施、大量申請ではない）

- URL検査で `https://inu-taikenki.com/about.html` と `https://inu-taikenki.com/about` を**検査のみ**（「インデックス登録をリクエスト」は押さない）し、「ユーザーが指定した正規URL」と「Googleが選択した正規URL」をメモする。

## 6. 改善実験の設計

### 6-1. 方針

- 目的：同じ時期・同じ型の記事を「改稿する／しない」に分け、**内容改善後の登録・表示回数・クリック数の変化**を探索する。サンプル数が少なく、検索需要・公開時期等の交絡もあるため、因果関係の実証やB1/B2の完全な切り分けはできない。
- **実験前に必ず記録**：改稿側と比較側の直近28日間（取得可能な範囲）の検索表示回数・クリック数・検索クエリ・登録状態・最終クロール日。公開日と変更差分も保存し、取得不能な項目は未取得と明記する。
- 文字数やFAQを増やすことは目的にしない。**読者が商品を選ぶときに使える、このサイトにしかない判断材料**を加える。
- **今すぐ使える適法な情報**：メーカー・販売元の公式仕様（サイズ、重さ、刃の方式、対象体重、素材など。事実の情報で、出典を明記）、獣医・公的機関・保険会社などの公開ガイドへのリンクと要点、サイト内のデータから運営者が行う集計（すでに表示している件数の再整理）、運営者自身の使用・計測（あれば）。
- **使い方を変える情報**：利用許諾が未確認の第三者レビューの要約は、データとしては残すが、**記事の結論や代表例には使わない**（削除はしない）。

### 6-4. 実施の順序と注意

1. 改稿の内容はdevelop向けPRで作り、ChatGPTの独立監査と運営者の承認を受ける（大規模な本文修正はこの手順の後）。
2. **本番公開のタイミングを揃える。** developには、本番に出ていないPR #115（7ページのtitle戻し、ブラシ4記事のFAQ追加など）がある。これにはbrush-comb・brush-pin・brush-slicker・brush-undercoat・dog-nail-grinderが含まれ、改稿と同時に公開すると**どの変更が効いたか分からなくなる**。選択肢：
   - A：先にPR #115を本番へ出し、2〜4週間観測してから改稿を公開する（推奨。比較がきれい）
   - B：PR #115のうち比較対象（brush-pin・dog-nail-grinder）に関わる変更を外して公開する
3. **最初の30日間は改稿側・比較側のどちらにも再登録リクエストを行わない。** 自然な再クロールを観測し、各URLのクロール日を記録する。改稿側だけ申請すると、記事改善と申請の影響を区別できない。
4. 事前のGSC指標を両群について保存してから本番公開し、公開日を「実験開始日」として記録する。30日後も再クロールがなければ効果は**未判定**とする。必要なら運営者承認後、両群へ同条件で各1回リクエストする別フェーズを設け、その結果を当初の自然観察と混同しない。

- 「新しいサイトでクロール・評価が不足（B2）」は**中〜高を維持**。公開時期との関連はあるが、未登録12記事中11記事の最終クロール日やサイト全体の統計がなく、クロール不足が主因とは断定できない。
- 「URL移行の影響（B3）」は、`/about.html` という**直接の具体例が見つかった**（一部は移行の残り）。ただし「約30→6」の減少自体は未確認。
- 新たに「登録状態が9月の内容で止まっていて、10/23以降の改稿が評価されていない（B4）」を加えた（有力な仮説）。

**2. インデックス未登録の最も有力な原因は何か？**
- **原因は未特定**。公開時期と登録状況の関連からクロール・再評価の遅れ（B2＋B4）は有力な仮説だが、未登録11記事のクロール履歴がなく、独自性（B1）やURL移行（B3）との寄与の比較はできない。第6章の観察とGSCデータの補完が必要。

**3. 本当に効果がありそうな改善は何か？**
- 公式仕様・判断表・運営者の一次情報で「このサイトにしかない判断材料」をつくる改稿を比較対象つきで2〜3本だけ試し、事前のGSC指標を保存した上で**両群とも再登録申請せずに**30日間観察すること（提言）。
- developに溜まった未公開のSEO変更（PR #115）の公開方針を決め、実験の比較を混乱させないこと（提言）。
- 新しい比較記事の追加を止め、同じ型のページを増やさないこと（提言）。
- 技術面は、`/about.html` を含めて経過観察でよい（追加のURL変更・noindex・大量申請はしない）。

**4. 最初に改稿すべき記事はどれか？**
- `/dog-nail-clipper`（未登録、比較対象 `/dog-nail-grinder`）、`/brush-comb`（未登録、比較対象 `/brush-pin`）、`/dog-shampoo`（登録済み、比較対象 `/dog-clipper`）。理由は第6章。

**5. 口コミ投稿機能の開発とSEO改善は、どちらを優先すべきか？**
- **SEOの改善実験を先に始め、口コミ投稿機能は並行して設計・開発を続ける**（提言）。理由：改善実験は今ある適法な情報（公式仕様・公的ガイド・サイト内の集計・運営者の実体験）で2〜4週間のうちに結果が出始めるが、本人投稿が集まって検索評価に効くまでには数か月かかる見込み。ただし、許諾の問題を根本から解決できるのは本人投稿なので、止めるべきではない。
